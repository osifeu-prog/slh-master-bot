# 📋 AGENT WORKFLOW - SLH_MASTER_BOT

## 🛠 Commands
- **st**: Check Railway status.
- **todo**: Edit the task list.
- **power**: View today's progress.
- **deploy**: git add . + git commit + git push.

## 📂 Structure
- /handlers: Bot command logic.
- /utils: Database & Keyboards.
- TODO.md: Task tracking.

## 🚀 Deployment
Push to 'main' branch triggers auto-deploy on Railway.
